# Apigee Hybrid on Azure AKS with Terraform & Azure DevOps

This repository contains the Terraform scripts to provision an Azure AKS cluster with specialized Apigee node pools, connect it to a Google Cloud Apigee control plane organization, and configure a multi-stage Azure DevOps pipeline for promoting API proxies across Dev, QA, UAT, and Prod.
